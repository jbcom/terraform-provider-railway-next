# Roadmap

## Phase 1: first usable release

Stabilize and run live acceptance coverage for the implemented project,
environment, service, volume, variable collection, secret, service domain,
bucket, and PostgreSQL resources plus their five data sources. Validate the
complete example's apply, second plan, fresh-state imports, and destroy.

## Phase 2: deployment and networking depth

Add first-class deployment controls and waiters, TCP proxies, private
networking, cron services, GitHub trigger configuration, build/deploy logs,
volume backups, and custom-domain certificate/DNS diagnostics.

## Phase 3: broader Railway platform

Add shared variables, templates, MySQL/Redis/Mongo composites, project members
and access controls, observability/alerts, environments copied from PRs,
functions, canvas groups, and additional storage lifecycle operations exposed
by stable Railway APIs.

## Phase 4: import and migration tooling

Add list-resource support where Terraform and Railway schemas permit it,
machine-readable import discovery, state migrations for renamed provider
addresses, and fixture compatibility checks across Railway schema/SDK
versions.
